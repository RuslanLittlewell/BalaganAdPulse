## Decisions

- **A plus button instead of a self-growing list.** The dialog opens with the project's KPIs
  as blocks, and with one empty block when it has none. A plus button after the last block
  appends an empty block. It is disabled while the last block is still empty and absent once
  the project holds five.
- **The circle says whether a KPI counts.** It sits before the tile's title, green for counted
  and grey for not, named for assistive technology. A KPI that does not count is otherwise
  drawn as any other: its figures, progress and status stay, because the reader still wants to
  see how it is doing.
