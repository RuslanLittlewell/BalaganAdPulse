## ADDED Requirements

### Requirement: The project search field carries an icon

The search field above the project list SHALL show a search icon at its left edge, inside the
field, so that its purpose is clear before anything is typed. The icon SHALL NOT take focus or
intercept clicks on the field.

#### Scenario: An empty field
- **WHEN** a member opens the project list
- **THEN** the search field shows a search icon beside its placeholder
