## Why

The interface language should be chosen through a select rather than an English on/off switch.

## What Changes

- Use the existing Select with Russian and English options.
- Keep the plain row layout, with its label on the left and control on the right.
- Preserve saved preferences, language reload and dialog closing behavior.
- No breaking changes.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. Existing language requirements remain intact; only the control changes.

## Impact

The profile dialog, its unused language-switch label and existing behavior expectations change.
